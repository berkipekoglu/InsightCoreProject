# Phase 1: Infrastructure & Database Schemas - Quick Start Guide

This guide will walk you through setting up and verifying the core infrastructure components of the InsightCore project, as defined in Phase 1.

## Prerequisites

Before you begin, ensure you have the following installed:

*   **Docker Desktop:** Required to run all services in isolated containers.
*   **Git:** For cloning the project repository.

## Project Structure

The InsightCore project is organized into several services, each with its own directory:

*   `collector-api`: Node.js Fastify API for data ingestion.
*   `processor-worker`: Node.js worker for processing events from RabbitMQ.
*   `dashboard-frontend`: Next.js application for the user interface.
*   `docs`: Nextra documentation site (this site).

## Core Services

The `docker-compose.yml` file orchestrates the following core services:

*   **PostgreSQL:** Primary database for user accounts, organizations, and projects.
    *   DB: `insightcore_db`
    *   User: `insightcore_user`
    *   Password: `insightcore_password`
    *   Port: `5432`
*   **ClickHouse:** Analytics database for `heatmap_events` and `session_events`.
    *   DB: `insightcore_analytics`
    *   User: `insightcore_user`
    *   Password: `insightcore_password`
    *   HTTP Port: `8123`
    *   Client Port: `9000`
*   **RabbitMQ:** Message queue for event processing.
    *   User: `insightcore_user`
    *   Password: `insightcore_password`
    *   AMQP Port: `5672`
    *   Management UI Port: `15672`
*   **MinIO:** S3-compatible object storage for `rrweb` JSON blobs.
    *   User: `insightcore_minio_user`
    *   Password: `insightcore_minio_password`
    *   API Port: `9002`
    *   Console Port: `9001`

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd insightcore-project
    ```

2.  **Start all services:**
    Navigate to the root of the project (`D:\Projects\InsightCore Project`) and run:
    ```bash
    docker-compose up --build -d
    ```
    This command will:
    *   Build Docker images for `collector-api`, `processor-worker`, `dashboard-frontend`, and `docs`.
    *   Start all defined services in detached mode (`-d`).

3.  **Verify Services:**
    Once all services are up, you can verify their status by accessing their respective interfaces:

    *   **Dashboard Frontend:** [http://localhost:3001](http://localhost:3001)
    *   **Documentation Site:** [http://localhost:3002](http://localhost:3002)
    *   **MinIO Console:** [http://localhost:9001](http://localhost:9001) (Use `insightcore_minio_user` / `insightcore_minio_password`)
    *   **RabbitMQ Management UI:** [http://localhost:15672](http://localhost:15672) (Use `insightcore_user` / `insightcore_password`)

    You can also check the logs of individual services:
    ```bash
    docker-compose logs -f <service-name>
    # Example: docker-compose logs -f collector-api
    ```

## Stopping Services

To stop and remove all services, volumes, and networks created by `docker-compose`:

```bash
docker-compose down -v
```

This concludes the Quick Start Guide for Phase 1. You now have a fully operational local development environment for InsightCore.
